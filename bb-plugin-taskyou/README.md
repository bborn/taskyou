# TaskYou for bb

An optional bb sidebar for your existing TaskYou queue. Browse the board,
filter by project, search tasks, create or edit work, queue it, retry with
feedback, and close completed tasks. The detail view includes recent logs.
Changes made in the CLI, TUI, or browser reach the board through TaskYou's
event stream.

TaskYou owns the data and executor. This plugin uses its HTTP API through
bb's server; it does not create bb tasks, threads, or worktrees.

## Install

Requires bb 0.43 or newer (Plugin SDK 0.4.87+) and TaskYou with its HTTP API.
From a checkout of this repository:

```sh
cd bb-plugin-taskyou
npm ci --include=dev
bb plugin build
bb plugin install .
```

After this change is merged, install directly from Git:

```sh
bb plugin install git:https://github.com/bborn/taskyou.git@main --subdirectory bb-plugin-taskyou
```

For a PR branch, replace `main` with that branch name. Git installs need npm
and build the plugin from source; generated bundles are not committed.

Open **TaskYou** in bb's sidebar.

## Connect

The default API URL is `http://127.0.0.1:8484`. If TaskYou's daemon already
serves that address, use it. Otherwise, run this on the TaskYou machine:

```sh
ty serve --host 127.0.0.1 --port 8484
```

Task execution also requires TaskYou's daemon (`ty daemon`). The plugin does
not launch either process.

Set **API URL** under Settings → Installed plugins → TaskYou, or use:

```sh
bb plugin config taskyou set apiUrl http://127.0.0.1:8484
```

The address is resolved on the **bb server machine**, not your browser or
agent host. For a separate TaskYou machine, use a trusted private connection
reachable from that server. The API grants control of execution; do not
publish an unauthenticated TaskYou API on the internet. URLs must use HTTP
or HTTPS with no embedded credentials, query, or fragment. A path prefix is
supported for reverse proxies. Redirects are rejected.

Setting changes reconnect automatically. If the board cannot connect, check
the URL, confirm the API is running, and inspect `bb plugin logs taskyou`.
Use Refresh after restoring the connection. The plugin reconnects its event
stream and refreshes after bb's realtime socket reconnects.

## First-version scope

- Four columns: Backlog, In progress (queued and processing), Blocked, Done.
- Up to 200 tasks per status, with a visible warning when a result is capped.
  Search and project filters apply to these loaded tasks.
- New tasks start in backlog unless you explicitly choose to queue them.
- Task types and executors come from TaskYou, not bb's provider catalog.
- Editing preserves unsupported settings such as permissions and placement.
- TaskYou currently cannot clear an existing task type through PATCH; select
  another type or leave the current value.

Use TaskYou's standalone surfaces for terminals, attachments, manual host
placement, project administration, and other advanced operations. This plugin
is an additional client, not a replacement for the existing browser or
desktop app. The existing CLI/TUI/GUI parity contract remains in force.

## Development

```sh
npm ci --include=dev
npm run typecheck
npm test
bb plugin build
bb plugin types --check
```

For live development after installation, `bb plugin dev` rebuilds and reloads
on save. Test writes against a disposable TaskYou database, without a daemon
running against it, so queue/retry checks do not launch agents.

The SDK declarations are pinned in `package.json`. Use `bb plugin types`
and then `npm install` when intentionally upgrading to another bb version.
The UI primitives under `components/ui/` are generated by `bb plugin new`
from bb's component registry, with local copies owned by this plugin.
